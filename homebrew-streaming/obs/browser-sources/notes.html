🎬 PRE-STREAM CHECKLIST

📋 Before Going Live

  • Caps+B Stream-safe + captions ON
  • Caps+L Live captions toggle (if separate)
  • OBS → Start Streaming
  • YouTube Studio → Visibility: Unlisted (or Public)

🎮 During Stream

  • Caps+M Mark moment (clip target)
  • Mouse5 Voice dictation (paste)
  • Watch caption status indicator (top-right of canvas)

🛑 End of Stream

  • OBS → Stop Streaming
  • Caps+N Normal mode (revert)
  • YouTube Studio → end broadcast
  • Run ~/stream/scripts/clip-extract.sh on VOD
